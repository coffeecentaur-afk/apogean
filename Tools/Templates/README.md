# Native framing masks

`TerrariaTerrainFrameMask.png` and `TerrariaWallFrameMask.png` are pinned copies of the official tModLoader ExampleMod framing templates at commit `b596b760ee90dc27d11dad756d955fb3f7da795e`.

The Apogean generators use only their opaque/transparent topology. All visible material colors, clusters, seams, damage, amber growth, and faction motifs are generated by Apogean. Keeping the mask local makes builds deterministic and prevents a network dependency.
