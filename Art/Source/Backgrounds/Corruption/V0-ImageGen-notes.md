# Corruption V0 ImageGen source notes

## Intent

Corruption V0 depicts a ruined industrial metropolis that has been infected rather than replaced by the biome. The authored reference remains `V0-Day-source.png`. ImageGen was used in generation mode to decompose that composition into three depth-specific source plates; `Tools/New-CorruptionBackgroundPrototype.ps1` performs the deterministic crop, hard-palette reduction, nearest-neighbor scaling, lower-edge closure, and exact Terraria layer export.

## Far extraction prompt role

Create only the distant atmospheric layer: a pale-violet industrial skyline with refinery stacks, spherical containment domes, broken towers, thin smoke plumes, and a few tiny burning aerial wrecks. Keep the lower skyline continuous, preserve broad empty sky above it, avoid foreground detail, use crisp pixel-art edges, and place the artwork on a neutral checker preview so it can be removed deterministically.

## Mid extraction prompt role

Create the readable architecture layer: a dark ruined refinery on the left, circular sewer mouths and infected pipes, a sagging broken bridge crossing a broad open center, and a ruined gabled research building on the right. Thread violet corruption tendrils through surviving industrial masonry without turning the whole image neon. Keep the central combat view open and use crisp pixel-art edges on a neutral checker preview.

## Close extraction prompt role

Create only the nearest framing rim: near-black thorny roots, ruptured pipes, corrupted rubble, and sparse violet nodes rising primarily at both sides while leaving a broad low opening through the middle. The shape must frame gameplay rather than cover it. Use crisp pixel-art edges on a neutral checker preview.
