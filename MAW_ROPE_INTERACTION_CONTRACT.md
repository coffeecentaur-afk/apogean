packed anatomy candidate, no active performance sample or item animation. Reserve
at least 32 free global item slots; otherwise refuse without tile writes.

Select a dry, wall-free 32×32 empty patch with a 12-tile initially empty framing
halo, away from known specimens, protected structures and actors. Snapshot exact
native cell storage. Restore the scratch and newly created local drops after each
case and in `finally`; compare known history fingerprints afterward. Unknown
historical locations remain explicitly unverified. No player equipment, health,
position, velocity, inventory or saved specimen edits.

16-cell ordinary ropes, with cardinal top/left/right/bottom anchors. Frame and
recognize each rope cell; use native `PickTile(35)` on one middle segment, verify
15 remaining segments and one actual rope drop. Remove the original support and
observe native rope persistence. An isolated direct API placement documents why
`PlaceTile` success is not proof of player item-use placement.

Separately mine candidate rib with 30 rejected pick58 calls then bounded pick59
calls; mine candidate cap with bounded pick35 calls. Record registered and actual
drops, including missing diagnostic item bindings, without inventing shipping
pickup support. This path exercises mining hooks but bypasses reach and swing
timing. New-case work stops after two seconds; this is not a frame-time target.

Complete evidence requires 15 cases, two real negative controls, unchanged local
storage/history, and 671 checks. Partial failures must retain their raw reports.
An independent report checker rejects optimistic counts, missing drops, changed
hashes and API/player conflation. A passing checker alone is not native proof.

## Separate input-driven comparison

Next prototype uses a separate native-created Classic starter character named
**Maw QA Rope**, not the preserved Plain baseline. Only three named comparisons,
stop and safe exit are accepted; automatic grove construction is suppressed.
Its ephemeral empty32×32 patch has a gray-brick landing floor,20 ordinary rope
cells and a gray-brick or candidate-rib top support. The matched `none` control
keeps rib/floor geometry without rope. SetControls supplies Up for180 updates
then neutral input for30. Setup/teardown alone relocate the player; measured
motion never sets velocity, position or pulley. Native pulley samples,128px
minimum rise and at least30 upward pulley updates are required for ascent.

Every case is bounded to210 updates/eight seconds; context, menus, focus, death,
damage, loadout, forbidden movement mode and envelope changes abort. UI updates
also stop a paused/focus-lost run. Stop/new request/unload release owned input.
Scratch snapshots restore before report serialization, and the original player
position/fall state is restored after sampling. No health/equipment/item grants,
no movement in regular worlds, no item-use or top-exit claim. Native V results now
prove the bounded ascent comparison, not complete traversal. No production rope added.

Actual item placement must use the native item-use path with supported and
unsupported controls. Actual ascent must record input-driven native pulley
acquisition and upward travel, with a matched no-rope failure control. Neither is
proved by the API microchecks alone. Hand-played feel, full-route returnability, multiplayer,
natural hazard balance and production worldgen remain separate gates.
